# Bina.az Qiymət Analizatoru

Chrome genişləndirməsi ki, bina.az saytında mənzil qiymətlərini təhlil edir və kvadrat metr başına qiyməti rəngli dərəcələndirmə ilə göstərir.

## Quraşdırma

### 1. Kodu yükləyin

```bash
git clone https://github.com/your-username/bina-az-chrome-extension.git
```

### 2. Chrome-a əlavə edin

1. Chrome-da `chrome://extensions/` ünvanına daxil olun
2. Sağ yuxarı küncdə **Developer mode** (Tərtibatçı rejimi) açın
3. **Load unpacked** düyməsini basın
4. `bina-az-chrome-extension` qovluğunu seçin

### 3. İstifadə etməyə hazırdır!

[bina.az](https://bina.az) saytına daxil olun və elanların altında kvadrat metr başına qiymətləri görün:

- 🟢 **Yaşıl** = Əlverişli qiymət
- 🟡 **Sarı** = Orta qiymət
- 🔴 **Qırmızı** = Bahalı

Genişləndirmənin ikonuna klikləyin və statistikaya baxın.
